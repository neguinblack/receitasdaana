# A Arte de Fazer Bolos - Landing Page

## 🚀 Como Aparecer no Google e Redes Sociais

### 1. SEO Básico (Já configurado)
✅ Meta tags otimizadas
✅ Sitemap.xml criado
✅ Robots.txt configurado

### 2. Google Search Console (IMPORTANTE)
1. Vá em: https://search.google.com/search-console
2. Adicione propriedade: `bolosanapaula.github.io`
3. Verifique propriedade (GitHub Pages facilita)
4. Submeta o sitemap: `https://bolosanapaula.github.io/sitemap.xml`

### 3. Google Analytics (Opcional)
1. Vá em: https://analytics.google.com
2. Crie propriedade
3. Adicione código no `<head>` do HTML

### 4. Redes Sociais - COMPARTILHE!
**Instagram:**
- Poste foto do site
- Use hashtags: #EbookBolos #Confeitaria #ReceitasBolos
- Faça stories com link

**Facebook:**
- Poste no seu perfil/página
- Grupos de confeitaria
- Anúncios pagos (R$10-20/dia)

**WhatsApp:**
- Compartilhe com grupos de mães/amigas
- Status com link

**Pinterest:**
- Imagens dos bolos do ebook
- Link para o site

### 5. Backlinks (Links de outros sites)
- Peça para blogs de culinária linkarem
- Participe de fóruns de confeitaria
- Anuncie em grupos do Facebook

### 6. Otimizações Extras
- Use palavras-chave: "ebook bolos", "receitas bolos", "confeitaria profissional"
- Imagens com alt text
- Velocidade do site (GitHub Pages é rápido)

### 7. Anúncios Pagos (Quando tiver orçamento)
- Google Ads: R$5-10/dia para "receitas de bolos"
- Facebook Ads: R$10-20/dia para público interessado em culinária
